# TalkingEditor 通用剪辑 Agent

先读 [使用说明](00Code/README.md) 和 [执行技能](skills/talking-editor/SKILL.md)，复用 `00Code` 中的引擎。

- 以收件人本次给出的素材、语言、标题、剪辑强度、字幕和封面要求为准。未提供的样式按技术默认值预览，可随时修改；不推断任何个人偏好或继承其他工作区的历史约定。
- 原片保持不变，输出写入独立目录。标题与文案只根据实际视频、字幕或用户提供的信息生成。
- 标题可由用户指定，也可在用户授权自动选择后从候选中选择；需要用户选择时明确呈现候选。
- 可将审核后的字幕交给相邻的 `02DYXHSTitleTag` 生成平台文案。发布功能由相邻发布 Agent 负责，必须使用收件人自己的平台账户。
- 使用本地 Python 环境；不读取、复制或请求原作者的令牌、账户、浏览器会话、历史素材或个人配置。
- 封面排版、颜色、人物处理方式和比例由收件人选择。引擎可验收与视频同比例的单张 PNG，或 1080×1440 与 1440×1080 的双封面。
- 图片生成取决于当前助手是否提供相应工具；终端脚本不会自动调用图片生成服务。收件人也可手动制作封面并传入路径。
- 完成前检查真实输出与报告，说明识别错误、保留原时长或功能限制；不能将只完成转写的任务说成已完成成片。
