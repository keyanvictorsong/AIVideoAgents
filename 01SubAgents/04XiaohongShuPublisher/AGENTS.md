# 小红书发布准备 Agent 的通用执行约定

- 本包只复用流程和源码，账号、文案风格、标签、封面和发布选择都由当前使用者决定，不继承原作者偏好或授权。
- 接收 01 定稿视频和 3:4 竖封面，读取 02 本条小红书标题、正文和标签后准确传入 prepare。CLI 不自动导入 02 JSON。标题/正文过长时先处理本条问题，不擅自改写确认内容。
- 首次先适配 selectors.example.json 的六个必要封面控件和预览位置；缺少配置则在上传前停止。只依据本人当前页面定位，不能把离线 fixture 当成真实站点选择器。
- 默认复用本人 .local/browser-profile；显式指定其他 profile 时只用当前使用者选择的专用目录。不读取日常浏览器资料，不复制别人 Cookie。账号登录和验证由本人在专用窗口完成。
- 登录备份 .xhs-auth-session.json 仅存于本人 profile，权限 0600；只恢复缺失且未过期状态，不延长有效期、不输出凭据。大陆/海外入口服从本人实际官方跳转，不强制所有人使用某个账号的路由。
- 核对真实封面上传、编辑预览和应用缩略图。不能把默认视频帧、文件框已选择、编辑器关闭或按钮可点当作成功。实际裁切和文字可读性须在平台检查。
- 素材、正文和封面准备好后保持交互式终端及浏览器可见，由本人最终点击发布。没有 --publish 或 --no-review，也不添加自动提交入口。本人完成网页操作后才在等待终端按回车。
- 区分 awaiting_user_publish、人工交接和实际发布。只读核对作品管理再记录实际结果；不能因日志仍待发布就重新上传。
- 保留 profile 锁、manual-handoff.json 和 SHA ledger。原表单丢失后，仅在已做只读核验并有本人明确未提交说明时，按 jobs.authorize_repreparation 完成绑定本视频的单次恢复；不删除历史标记或伪造授权。
- 本地回归只用合成素材与临时目录，tests/run_offline.py 禁止联网且不启动浏览器。完整浏览器测试只用本地网络拦截页面，不登录/发布真实账号。未经现场验证，不声称真实上传已完成。
- 运行输出、日志、截图和 .local 都不属于可分享源码；生成新的分享包时须重新排除。
