# 文案 Agent 执行说明

适用本目录。按收件人当次要求确定文风、选题、标签与长度，不承接其他人的历史偏好。

1. 接收收件人自己的视频，先运行 `dyxhs run`，通过 `--output` 指定本条视频的文案工作目录。需要完整离线处理时加 `--skip-collect`，且不要启用外部模型。
2. 读取完整字幕、来源标记及必要抽帧，先核对事实，再写候选文案。无字幕时可接收用户描述并保留来源标记；不要把描述冒充实际观察。
3. 无独立模型时，根据生成的 `generation_request.md` 制作 `reviewed_facts.json` 与 `reviewed_copy.json`，原样复制当前视频和证据指纹，引用实际证据及事实 ID，再用同一目录恢复运行。
4. 推荐与备选仅供选择；最终成片标题和发布文案由当前用户确定。将已选定文案交给发布 Agent，不把草稿当作发布授权。
5. 如需参考采集，查询词来自本次内容。只使用收件人自己的专用会话或其提供的导出；不读取其他浏览器档案。遇验证或限流保留真实状态，不编造样本、日期、热度或标签认证。
6. 导出后检查事实关联、状态与文件；退出码 2 不等于完全成功。交付简短说明可用文案及实际限制。

运行产生的 `.env`、`.local/`、`output/`、素材及审核文件属于收件人的私人数据，后续分发时不纳入工具源码包。
