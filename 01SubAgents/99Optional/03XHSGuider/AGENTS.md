# 可选研究 Agent 执行说明

本模块仅按当前用户明确需求运行，不自动加入剪辑和发布流程。

- 按本批次需要提供 `--query` 与可选 `--keyword`，不使用其他人的历史主题、文风或选样。
- 优先处理用户自己的真实导出和缓存；需要在线登录时，只创建或使用收件人自己的专用会话。
- 严格区分标题/正文等元数据、字幕和实际画面。没有内容证据就保留初步状态，不声称已看完整视频，不虚构传播机制、互动数据或评论。
- 报告记录实际样本数量、采集时间、筛选参数及阻断状态。样本不足时导出部分报告，不补造样本或静默挪动平台名额。
- 输出、账号会话和素材是当前用户的数据；后续分发只包含源码与通用说明。
