# 抖音发布 Agent 的通用执行约定

- 本目录为可分享源码，不包含其他人的身份、账号、喜好、素材或登录状态。所有主题、文案、话题、合集和声明都以当前使用者本条任务为准；不要从示例推断长期偏好。
- 优先接收 01 的定稿成片和横竖双封面、02 的 douyin-copy.json，使用 --copy-file 与 --cover-vertical / --cover-horizontal 成对交接。原片和剪辑片的 SHA 分开记录；保留 topic_selection。不要重新绘制已经确认的封面。
- 首次使用先根据本人页面适配 selectors.example.json；缺少封面预览配置时停止上传。页面选择器不包含账号授权，不沿用别人机器上的 .local。
- 登录仅在本人专用 profile 内进行；默认 .local/browser-profile。Cookie、token、localStorage、浏览器资料和私密 URL 不进入交付文档、普通产物或聊天，不读取日常浏览器资料。
- 默认上传准备后停在交互终端等待，保持浏览器可见供本人检查、亲自发布。不得继承旧用户的自动发布授权。只有当前使用者对本次作品明确授权时，才可显式传 --publish；不额外要求已授权的流程再次确认。
- 必须实际上传并核对 3:4 竖图及 4:3 横图；只有导入编辑预览和主页面实际缩略图均通过才算完成。默认帧、占位卡、文件框已选择或弹窗关闭都不算成功。两步编辑器需先竖图，再横图，再真正完成。
- 保留原文和已选话题实体；相关性优先，没有足够相关候选则少选，不编造热度或统计时间。未指定合集则不选择任何合集。
- 保留 submission_guard、publish-attempt.json 和 ledger；结果不明确时只读检查作品管理，不重传、不重试提交。filled 或截图不能当成已发布，人工提交后仍需核对真实作品记录。
- 本地测试使用合成素材和临时目录。tests/run_offline.py 不启动浏览器且禁止联网；完整浏览器测试仅对本地拦截 fixture 运行。没有当前账号的真实页面证据，不声称本次发布已完成。
