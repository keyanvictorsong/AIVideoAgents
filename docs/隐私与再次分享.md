# 隐私与再次分享

本次分享使用源码白名单重新整理，未打包发送者的账号、登录状态、密钥、私人素材或历史任务。包内的测试数据和示例用于说明程序，不提供可登录的真实凭据。技术参数是可修改的初始值，个人约定与日更授权未继承。

首次运行后，以下内容会变成你自己的私人资料，切勿把整个使用过的文件夹直接再次转发：

- `.local`、浏览器 profile、Cookie、localStorage、sessionStorage、认证快照和发布台账。
- `.env`、API key、token、账号设置、选择器配置内可能存在的账户信息。
- `02VideoWorkSpace` 下的素材、转写、截图、文案、结果和任务记录。
- `.venv`、模型缓存、日志、Git 历史及安装生成的元数据。

初始分享包附有 `MANIFEST.json`，列出交付文件、大小与 SHA256。运行 `python3 tools/check_share.py` 可以检测交付文件的变化、额外文件、常见私有文件及凭据特征；它不会输出匹配到的密钥内容。使用过的副本会因新建运行数据而检查失败，这是预期行为。

该检查是本地静态筛查，不能替代人工审阅，也不会确认平台账号状态。再次分享时应从干净源码重新整理，只放通用说明、源码、合成测试和必要模板；重新审阅后生成新清单。不要为了通过检查而把私人文件加入清单。

Git 克隆的副本带有本机 `.git`，应按 [GitHub 获取与更新](GitHub使用与更新.md) 使用 `python3 tools/check_share.py --repo` 检查暂存快照。默认无参数检查仍用于干净 ZIP 分发目录，会严格拒绝额外文件。维护者使用 `tools/build_share.py` 显式更新清单或导出包；导出只使用审核后的文件名单，不会从整个工作目录自动收录内容。

本包安装器只安装公开依赖，不导入发送者设置。API 如有需要，由你自行配置；费用及模型服务账号也由你自己管理。
