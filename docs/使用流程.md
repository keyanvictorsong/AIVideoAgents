# 从自己的视频开始

在本包根目录运行命令。也可以把本说明交给你的 AI 编程助手，让它根据实际内容操作并展示关键结果。

## 1. 新建任务

```bash
python3 tools/new_task.py demo --video "/path/to/your-video.mp4"
```

任务内有 `00Input`、`01Edit`、`02Copy`、`03Douyin`、`04Xiaohongshu`、`records`。脚本保留原视频，并在任务副本上记录 SHA256。不传 `--video` 时只创建空目录。

告诉助手这是口播、运动、教程还是其他视频，以及你希望的语言、节奏、字幕、封面和目标平台。`task.json` 的风格、标题、目标平台和发布授权初始为空，需要按你的本次要求填写。

## 2. 分析与剪辑

```bash
python3 tools/agent.py edit "02VideoWorkSpace/demo/00Input/your-video.mp4" --output "02VideoWorkSpace/demo/01Edit" --analyze-only
```

先听看原片，核对转写、删减和字幕。审核后的剪辑计划可通过 `--plan` 传回程序；确认后再渲染。底层 `edit` 入口处理剪辑；需要 `content.txt`、标题与封面交付时，可用 `python3 tools/agent.py deliver --help`，具体配置及流程见 01 的 `00Code/README.md`。运动连续画面请使用可选运动字幕模板，不要直接套用口播剪切。

## 3. 标题、简介与标签

02 可读取字幕、OCR 和你提供的内容描述，当前助手核对事实后提供 `reviewed_facts.json` 和 `reviewed_copy.json`，再由 02 校验并导出。具体结构及命令以 02 的 README 为准。

复用 01 字幕时，把与当前视频时间线匹配的字幕复制到该视频旁，文件同名，例如 `edited.mp4` 对应 `edited.srt`；02 会自动读取这个旁挂文件。01 的 `captions.srt` 对应剪辑后时间线，只能交给对应的成片，不能配到原片。ASR 转写应作为识别证据保留来源，不能通过 `--content-file` 冒充本人写的描述。还没确定标题时可先导出无标题字幕版供 02 分析，再复用相同剪辑计划做定稿。

参考检索需要本人会话；平台验证或访问受限时可以如实记录限制并依据原片拟题。禁止为了“热门”虚构播放数。不要把 ASR 文字伪称为本人写的描述。

确定本次标题后，记录选择，导出 `douyin-copy.json`，完成最终视频、字幕及封面。视频文字、封面文字和平台标题可按本次需求分别调整，实际字数预算以页面为准。

## 4. 准备抖音

已有定稿视频和双封面时，03 支持直接复用封面；完整参数见 03 README。`prepare` 只生成本地任务，不上传。示例中的文件应先由前序步骤实际生成：

```bash
python3 tools/agent.py douyin prepare "02VideoWorkSpace/demo/01Edit/edited.mp4" --copy-file "02VideoWorkSpace/demo/02Copy/douyin-copy.json" --cover-vertical "02VideoWorkSpace/demo/01Edit/cover-vertical.jpg" --cover-horizontal "02VideoWorkSpace/demo/01Edit/cover-horizontal.jpg" --output "02VideoWorkSpace/demo/03Douyin"
python3 tools/agent.py douyin --channel chromium --selectors "01SubAgents/03DouyinPublisher/.local/selectors.json" upload "02VideoWorkSpace/demo/03Douyin/manifest.json"
```

检查真实竖/横封面、标题、简介、话题实体和声明。默认不传 `--publish`，由本人最终点击。若本人已明确授权本次自动提交，抖音可使用该显式参数。任务结果未知时先核对平台，不能反复上传提交。

首次适配当前页面的封面选择器后，用 `--selectors <你自己的配置.json>` 放在 `upload` 之前传入；03/04 的空模板和 README 给出各自字段。空模板本身不能作为已经适配完成的配置。

## 5. 准备小红书

04 使用已有视频和竖版封面；标题、简介、标签从 02 的小红书输出中读取或复制。本例标题和说明仅为占位，实际使用前替换：

```bash
python3 tools/agent.py xhs prepare "02VideoWorkSpace/demo/01Edit/edited.mp4" --cover "02VideoWorkSpace/demo/01Edit/cover-vertical.jpg" --title "替换为已确认标题" --description "替换为本期简介" --tags "" --output "02VideoWorkSpace/demo/04Xiaohongshu"
python3 tools/agent.py xhs --channel chromium --selectors "01SubAgents/04XiaohongShuPublisher/.local/selectors.json" upload "02VideoWorkSpace/demo/04Xiaohongshu/manifest.json"
```

在本机交互式终端执行上传；保持终端和浏览器打开。检查表单及封面后，本人点击平台最终发布按钮。当前 CLI 不自动完成小红书最终提交。

## 6. 保存本次结果

把最终视频、字幕、文案、封面和可公开的结果记录留在任务目录。平台显示已提交不等于审核通过，填好页面不等于已经发布。账号登录状态与认证快照应仅保留在本机 `.local`，不随任务或分享包交付。
